## Confirmed finding

### F-1: uninstall documentation overstated `config.toml` immutability

Severity: documentation / public-contract accuracy.

The released documentation correctly required managed-profile cleanup before Plugin and Marketplace removal, but then stated that the complete uninstall flow did not edit `config.toml`. The supported Codex CLI necessarily persists removal of the exact Plugin and Marketplace registrations in Codex configuration. Release validation had already observed this legitimate semantic delta while confirming that unrelated configuration semantics remained unchanged.

Repair on the audit branch:

- `docs/plugin-installation.md` now distinguishes the ownership-aware managed-profile helper from the supported Plugin/Marketplace CLI removal commands;
- `docs/release-checklist.md` now permits only the exact registration-removal semantic delta in `config.toml` while requiring all unrelated configuration semantics to remain unchanged;
- `tests/test_uninstall_documentation_contract.py` prevents regression to the previous absolute wording.

This finding does not change runtime behavior, the tagged package identity, or the safety result of the completed `v3.0.0` uninstall gate.

## Residual risk reviewed, not promoted to a defect

The managed installer serializes cooperating installers with a persistent OS lock and verifies/rolls back publication-window drift. It does not claim a cross-session filesystem lock against arbitrary editors or unrelated external processes. A non-cooperating external writer can create a narrow filesystem TOCTOU window around ordinary pathname operations.

The project guardrails already place independent editors/processes outside the session-local scheduler, require preservation of unrelated edits, and explicitly avoid claiming cross-session locking. Existing concurrency and drift tests cover the supported cooperating-installer model. No reproducible cooperating-path data-loss defect was established during this audit. The non-cooperating external-writer race therefore remains a bounded residual risk rather than a release blocker.
