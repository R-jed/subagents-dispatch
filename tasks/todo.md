# 1.0.0 Clean-Break Closure Tasks

This file lists source obligations for the first public `1.0.0` clean break. Live completion state belongs in Git/GitHub. Do not edit this file merely to record a green CI run.

## Source obligations

- Remove all current callers and machine-schema fields for the retired TeamPlan design.
- Keep WorkGraph and WorkUnit as the sole current responsibility/dependency structure.
- Remove pre-1.0 migration, stale-state cleanup, and retired validator implementations from the shipped product.
- Reject unsupported pre-1.0 state, unsafe ownership, unsupported installation sources, and invalid current schema explicitly.
- Preserve `UNKNOWN` for genuinely ambiguous Host lifecycle, identity, materialization, permission, and writer evidence.
- Align public release identity with Plugin `1.0.0`, including the release checklist and final tag sequence.
- Keep Native Core V4 naming only where it identifies the internal architecture generation or machine contracts, not as the public Plugin release version.
- Keep task plans, AI guidance, and development handoff pointed at current truth owners without hardcoded stale candidate SHA, CI result, or old PR release state.
- Protect the clean break with regression tests that fail if retired compatibility artifacts or fields return to current authority surfaces.

## Repository merge gate

The current exact PR head must pass the complete platform matrix and aggregate `policy-tests`. The run must reach the managed Agent install/check/Doctor/uninstall lifecycle rather than being skipped after an earlier failure.

After the exact head is green, perform a fresh adversarial review across correctness, simplicity, architecture, security, and performance. Any required finding changes the candidate and therefore requires another exact-head verification run.

The first public release does not run a project-owned real-Host N0-N7 campaign. Release Host assumptions are pinned in `docs/v4/host-reference.json` to mature `sol-advisor` / `astra-advisor` implementations. The exact-source Department Director / Astra High Final Review remains a separate required gate after the candidate is frozen.
